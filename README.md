# Origami Fairy v2.1 — by Sylredhel

클리핑·새츄레이션으로 **실제 손실된 고역 파형($\Delta_{\text{HF}}$)**만 천장 안쪽으로 되살리고 접어 넣는 디테일 보존 새츄레이터 & 오리가미 클리퍼 VST3입니다.

## v2.1 주요 업데이트
1. **무한 주기 $C^2$ `SMOOTH FOLD` 전면 수정**: 기존 `std::copysign` 부호 반전 버그(0에서 튀고 +C에서 평평하게 멈추던 현상)를 제거하고, `±0.825C` 이하에서는 완전 선형(`0.000000` 오차)이면서 모든 피크/밸리(`±C`)를 $C^2$ 4차 다항식 캡으로 매끄럽게 감싸 **끝없이 연속 폴딩**되는 구조로 교체했습니다.
2. **자기 보정 입력 엔벨로프 팔로워 (`ENV FOLLOW` + `ENV REL`)**: 입력 레벨에 따라 `DRIVE`를 실시간 연동해, 큰 어택에는 풀 드라이브를 걸고 작은 꼬리(드럼 디케이·리버브 테일)에서는 드라이브를 `0 dB` 쪽으로 되돌려 소리가 늘어지거나 멍청해지는 현상을 막습니다. `DRIVE` 노브 외곽의 테라코타 라이브 인디케이터와 스코프 상단 `ENV DRV`로 실시간 동작을 확인할 수 있습니다.
